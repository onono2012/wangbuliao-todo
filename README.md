# 忘不了（wangbuliao-todo）

Android 待办/记事本 App「忘不了」的**发布渠道**仓库。

- 功能：待办/已办、紧急标注、定时提醒（精确闹钟）、分类管理（工作/生活/学习，可自定义）
- 包名：`com.wangbuliao.todo`
- **在线更新**：App 内置更新器请求本仓库 Releases 的 latest 接口；有新版本时启动强制更新并展示更新内容
- APK 资产命名规范：`wbl-v<版本名>-vc<versionCode>.apk`（更新器据 `-vcN.apk` 后缀解析版本号比较大小）

历史版本说明见 Releases 页各条目的「更新内容」。
