## 更新内容
- **底部导航大改版**：待办 / 日历 / 主题 / 设置 四页直达，切换更顺手
- **主题独立成页**：十套精美主题大卡片预览（炫彩 / 肖战 / 极光 / 暮山紫 / 鎏金 / 深海蓝 / 清新绿 / 暖阳橙 / 樱花粉 / 极夜黑），全屏渐变洗色 + 光斑氛围背景，切换即时全局生效
- **自定义照片主题**：相册选图 → 自动按屏幕比例裁剪 → 全屏背景 + 悬浮球圆贴 + 照片主色自动提取，一键做专属主题（可更换/移除）
- **全新日历页**：公历 + 农历 + 24 节气 + 除夕/春节/干支生肖；有事项的日期带圆点标记，点任意日期查看当天事项、一键为当天记一笔
- **文字可读性全面修复**：顶栏文字色按主题自动选黑/白并做对比度补偿，任何主题下都清晰可读
- **后台保活**：保活守护服务（前台服务常驻 + 开机自恢复），一键申请电池优化白名单；通知栏常驻显示未完成事项清单，点「打开管理器」直达应用管理页
- **随手记面板升级**：深色玻璃拟态 + 主题主色按钮，新增 📷拍照 / 🖼相册 / 🎤录音 直达按钮，媒体速记自动入「随手记」
- **悬浮窗瘦身**：悬浮球更小巧不挡视线，跟随主题即时变色/换图
- **震动体系**：新增「震动提醒」总开关；到期通知长-短-长震动、完成待办轻震反馈
- **待办转已办优化**：完成时震动 + 明确去向提示，已办自动沉底按完成时间排序

## 安装说明
下载 APK 后点击安装（需允许「安装未知应用」权限）。旧版本用户可通过 App 内「检查更新」直接覆盖升级，数据自动保留。
