# 忘不了 v1.5.0 更新说明

## 更新内容
- **桌面小组件**：长按桌面 → 卡片 → 搜索「忘不了」即可添加。4×2 可调大小卡片，桌面直接查看待办清单
- **快速勾选**：点任务左侧圆圈即标记已办，置顶通知/保活通知同步刷新，无需打开应用
- **快速新增**：点小组件右上角「+」直达新建任务页，随手记一笔更快
- **实时刷新**：应用内新增/编辑/删除/勾选任务后，小组件即时同步；开机/恢复数据后自动刷新
- 清单排序与应用内一致：置顶 > 紧急 > 提醒时间 > 创建时间

## 安装说明
下载 APK 后点击安装（需允许「安装未知应用」权限）。旧版本用户可通过 App 内「检查更新」直接覆盖升级，数据自动保留。升级后长按桌面空白处 → 卡片 → 找到「忘不了」添加到桌面。
