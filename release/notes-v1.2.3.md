## 更新内容
- **智能线路测速**：下载前自动并行测速所有更新线路（单条限时 5 秒不拖累整体），优先选最快线路，大幅提升更新速度
- **下载实时速度显示**：进度条同步显示当前下载速度（如「下载中 45% · 950KB/s」）
- **防缓存检查**：检查更新自动绕过中转代理旧缓存，第一时间发现新版本
- 多线路更新通道：raw / gh-proxy / ghproxy / jsDelivr 中转 + GitHub API 兜底，单线路失败自动切换
- 断点续传跨线路共用，sha256 + 文件大小双重校验
- 123 网盘同步备份分发
